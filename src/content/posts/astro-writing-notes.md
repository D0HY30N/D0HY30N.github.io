> 블로그의 카테고리와 본문 모양을 확인하기 위한 예시 글입니다.

기술 블로그 글은 완성된 강의일 필요가 없습니다. 오늘 확인한 내용 하나를 다시 찾아볼 수 있는 형태로 남기는 것부터 시작할 수 있습니다.

## 글의 흐름 정하기

짧은 학습 기록은 다음 세 가지 질문으로 구성해 봅니다.

1. 무엇이 궁금했는가?
2. 어떤 예제로 확인했는가?
3. 무엇을 알게 되었고 무엇이 남았는가?

소제목을 붙이면 내용을 나누어 읽기 쉽고, 오른쪽 목차에서도 원하는 부분으로 이동할 수 있습니다.

## 코드와 결과를 함께 남기기

코드를 붙일 때는 언어 이름을 적고, 아래에 결과를 짧게 설명합니다.

```js
const topics = ["HTTP", "Linux", "Astro"];
const notes = topics.map((topic) => `${topic} 학습 노트`);

console.log(notes);
```

위 예제는 각 주제 이름 뒤에 같은 문구를 붙여 새 배열을 만듭니다. 입력과 출력을 나란히 적으면 나중에 코드를 다시 이해하기 편합니다.

## 비교할 내용은 표로 정리하기

| 요소 | 활용할 때 |
| --- | --- |
| 문단 | 생각의 흐름과 이유를 설명할 때 |
| 목록 | 순서나 확인할 항목을 정리할 때 |
| 코드 블록 | 실행한 코드와 명령을 남길 때 |
| 표 | 같은 기준으로 여러 대상을 비교할 때 |

글을 마무리할 때는 다시 실험할 질문 하나를 남겨 봅니다. 작은 질문이 다음 학습 기록의 시작점이 될 수 있습니다.
