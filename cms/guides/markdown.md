# 마크다운 문법

이 문서는 CMS의 **작성 가이드**에서 보는 참고용 문서입니다. 블로그 글 목록·카테고리·검색에는 포함되지 않습니다. 왼쪽에서 원문을, 오른쪽에서 결과를 확인할 수 있습니다.

## 글을 쓰는 순서

1. CMS에서 **게시글 → 새 엔트리 만들기**를 누릅니다.
2. 제목·작성일·글 요약·카테고리·태그를 입력합니다.
3. 본문을 작성하고 미리보기에서 라이트·다크를 확인합니다.
4. 공개할 글은 **초안으로 보관**을 끄고 저장합니다.
5. GitHub Pages 배포가 끝나면 블로그에 반영됩니다.

본문 편집기는 항상 마크다운 원문을 표시합니다. 상단의 굵게·기울임·제목·코드·링크·이미지 버튼은 선택한 위치에 문법을 넣어 줍니다. Ctrl+B, Ctrl+I, Ctrl+K 단축키도 사용할 수 있습니다. 오른쪽 미리보기에서 실제 본문 모양을 확인할 수 있습니다. 확장 문법과 코드 옵션도 입력한 그대로 보존됩니다.

## 제목

글 제목은 CMS의 **제목** 칸에 입력합니다. 본문은 보통 `##`부터 시작하면 목차를 정리하기 좋습니다.

```markdown
## 큰 단락
### 작은 단락
#### 더 작은 단락
```

## 문단과 줄바꿈

문단 사이에 빈 줄을 한 줄 넣습니다. 줄을 한 번만 바꾸면 같은 문단으로 이어집니다. 문단 안에서 꼭 줄을 바꾸려면 줄 끝에 공백 두 칸을 넣거나 `<br>`를 사용합니다.

```markdown
첫 번째 문단입니다.

두 번째 문단입니다.
```

## 링크와 이미지

```markdown
[블로그](https://d0hy30n.github.io/)
![이미지 설명](/images/uploads/example.png)
```

[블로그](https://d0hy30n.github.io/)

새 이미지는 CMS의 **에셋**에서 업로드한 다음 이미지 URL을 복사합니다. 본문 도구 모음의 **이미지** 버튼에 URL을 붙여넣으면 현재 커서 위치에 이미지 문법이 들어갑니다. 이미 게시글을 작성 중이면 에셋 업로드는 별도 CMS 탭에서 진행하면 편합니다. 본문 이미지와 **대표 이미지**는 별개입니다. 대표 이미지는 글 상단에 표시됩니다. 이미지를 직접 작성할 때는 대괄호 안에 내용을 설명하는 문장을 넣으세요.

## 구분선과 문자 그대로 쓰기

빈 줄 사이에 `---`를 쓰면 구분선이 됩니다. 문법 기호를 글자로 쓰려면 앞에 역슬래시를 넣습니다.

```markdown
위 문단

---

아래 문단

\*별표 그대로\* / \# 샵 그대로
```

\*별표 그대로\* / \# 샵 그대로

## 카테고리와 글 정보

CMS에서는 각각의 입력 칸을 사용합니다. **본문에 아래 정보를 붙여 넣을 필요는 없습니다.** `.md` 파일을 직접 만들 때만 파일 맨 위에 작성하세요.

```yaml
---
title: HTTP 요청 분석 노트
published: 2026-09-13
description: 요청의 메서드와 경로를 읽는 순서
parentCategory: 보안
category: WEB
tags: [HTTP, WEB]
image: ''
draft: false
lang: ko
---
```

- `parentCategory`: 클릭되지 않는 대카테고리 이름입니다. 새 이름을 입력하면 자동으로 묶입니다.
- `category`: 클릭해서 글을 볼 수 있는 소카테고리입니다. 같은 소카테고리는 한 대카테고리에서만 사용하세요.
- `tags`: 카테고리와 별도로 붙이는 검색용 키워드입니다.
- `draft: true`: 블로그에는 표시하지 않습니다. 공개 GitHub 저장소의 파일 자체가 비공개가 되는 것은 아닙니다.
- `updated`: 수정일을 표시하고 싶을 때만 추가합니다.

## 저장 전 확인

- 제목과 본문의 큰 제목을 중복해서 쓰지 않았는지 확인합니다.
- 코드 블록의 시작·끝 백틱 개수가 같은지 확인합니다.
- 표 앞뒤와 문단 사이에 빈 줄을 넣습니다.
- 이미지가 보이는지, 대카테고리와 소카테고리가 맞는지 확인합니다.
- 라이트·다크 미리보기를 모두 확인합니다.
