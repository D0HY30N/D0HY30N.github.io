# 마크다운 문법

이 문서는 CMS의 **작성 가이드**에서 보는 참고용 문서입니다. 블로그 글 목록·카테고리·검색에는 포함되지 않습니다. 왼쪽에서 원문을, 오른쪽에서 결과를 확인할 수 있습니다.

## 글을 쓰는 순서

1. CMS에서 **게시글 → 새 엔트리 만들기**를 누릅니다.
2. 제목·작성일·글 요약·카테고리·태그를 입력합니다.
3. 본문을 작성하고 미리보기에서 라이트·다크를 확인합니다.
4. 공개할 글은 **초안으로 보관**을 끄고 저장합니다.
5. GitHub Pages 배포가 끝나면 블로그에 반영됩니다.

본문 편집기는 항상 마크다운 원문을 표시합니다. 상단에서 **H1·H2·H3, 굵게·기울임·취소선, 인라인 코드·코드 블록, 인용문, 목록·번호 목록·체크리스트, 구분선, 표, 링크, 이미지**를 넣을 수 있습니다. Ctrl+B, Ctrl+I, Ctrl+K 단축키와 Ctrl+Z 실행 취소도 사용할 수 있습니다. 오른쪽 미리보기에서 실제 본문 모양을 확인할 수 있습니다. 확장 문법과 코드 옵션도 입력한 그대로 보존됩니다.

## 제목

글 제목은 CMS의 **제목** 칸에 입력합니다. 툴바의 H1·H2·H3는 현재 줄의 제목 단계를 바꿉니다. 본문은 보통 `##`부터 시작하면 목차를 정리하기 좋습니다.

```markdown
# 가장 큰 제목 (H1)
## 큰 단락
### 작은 단락
#### 더 작은 단락
```

## 문단과 줄바꿈

문단 사이에 빈 줄을 한 줄 넣습니다. 줄을 한 번만 바꾸면 같은 문단으로 이어집니다. 문단 안에서 꼭 줄을 바꾸려면 줄 끝에 공백 두 칸을 넣거나 `<br>`를 사용합니다.

```markdown
첫 번째 문단입니다.

두 번째 문단입니다.
```

## 링크와 이미지

```markdown
[블로그](https://d0hy30n.github.io/D0HY30N.github.io2/)
![이미지 설명](/D0HY30N.github.io2/images/uploads/example.png)
```

[블로그](https://d0hy30n.github.io/D0HY30N.github.io2/)

1. 본문에서 이미지를 넣을 위치를 클릭하고 툴바의 **이미지** 버튼을 누릅니다.
2. 열리는 선택창에서 **업로드**로 내 컴퓨터의 이미지 파일을 선택합니다. 이미 올린 이미지를 다시 고르거나 URL을 입력할 수도 있습니다.
3. 이미지를 선택하고 **삽입**을 누르면 해당 위치에 이미지 마크다운이 들어갑니다. 대괄호 안의 `이미지 설명`은 이미지 내용을 설명하는 문장으로 바꿔 주세요.
4. **글을 저장하면 이미지도 함께 저장**됩니다. 저장 전에는 임시 `blob:` 주소가 보이고, 저장 후 `/D0HY30N.github.io2/images/uploads/...` 경로로 바뀝니다. 임시 주소는 직접 수정하지 마세요.

이미지 한 파일의 용량 제한은 **10MB**입니다. 본문 이미지와 **대표 이미지**는 별개입니다. 대표 이미지는 글 상단에 표시됩니다.

## 표

툴바의 **표** 버튼에서 열 개수와 내용 행 개수를 정하고 **넣기**를 누르면 표 틀이 생깁니다. 제목 행은 자동으로 추가됩니다. 각 칸의 `제목`과 `내용`을 바꾸면 됩니다.

```markdown
| 메서드 | 용도 | 상태 코드 |
| :--- | :--- | ---: |
| GET | 조회 | 200 |
| POST | 생성 | 201 |
```

| 메서드 | 용도 | 상태 코드 |
| :--- | :--- | ---: |
| GET | 조회 | 200 |
| POST | 생성 | 201 |

## 구분선과 문자 그대로 쓰기

빈 줄 사이에 `---`를 쓰면 구분선이 됩니다. 문법 기호를 글자로 쓰려면 앞에 역슬래시를 넣습니다.

```markdown
위 문단

---

아래 문단

\*별표 그대로\* / \# 샵 그대로
```

\*별표 그대로\* / \# 샵 그대로

## 카테고리와 글 정보

CMS에서는 각각의 입력 칸을 사용합니다. **본문에 아래 정보를 붙여 넣을 필요는 없습니다.** `.md` 파일을 직접 만들 때만 파일 맨 위에 작성하세요.

```yaml
---
title: HTTP 요청 분석 노트
published: 2026-09-13
description: 요청의 메서드와 경로를 읽는 순서
parentCategory: 보안
category: WEB
tags: [HTTP, WEB]
image: ''
draft: false
lang: ko
---
```

- `parentCategory`: 클릭되지 않는 대카테고리 이름입니다. 새 이름을 입력하면 자동으로 묶입니다.
- `category`: 클릭해서 글을 볼 수 있는 소카테고리입니다. 같은 소카테고리는 한 대카테고리에서만 사용하세요.
- `tags`: 카테고리와 별도로 붙이는 검색용 키워드입니다.
- `draft: true`: 블로그에는 표시하지 않습니다. 공개 GitHub 저장소의 파일 자체가 비공개가 되는 것은 아닙니다.
- `updated`: 수정일을 표시하고 싶을 때만 추가합니다.

## 저장 전 확인

- 제목과 본문의 큰 제목을 중복해서 쓰지 않았는지 확인합니다.
- 코드 블록의 시작·끝 백틱 개수가 같은지 확인합니다.
- 표 앞뒤와 문단 사이에 빈 줄을 넣습니다.
- 이미지가 보이는지, 대카테고리와 소카테고리가 맞는지 확인합니다.
- 라이트·다크 미리보기를 모두 확인합니다.
