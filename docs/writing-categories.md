# 마크다운에서 카테고리 설정하기

`src/content/posts/`의 `.md` 파일 맨 위에 대분류와 소분류를 함께 적습니다.

```yaml
---
title: HTTP 공부 기록
published: 2026-09-13
parentCategory: 보안
category: WEB
tags: [HTTP]
draft: false
---
```

- `parentCategory`: 대분류. 사이드바에서 클릭되지 않는 제목으로 표시됩니다.
- `category`: 소분류. 클릭하면 해당 분류의 글 목록이 표시됩니다.

위 글은 **보안 > WEB**으로 표시됩니다. 새 이름을 입력하면 해당 대분류와
소분류가 자동으로 만들어지므로 새 분류를 추가할 때 설정 파일을 수정할 필요가 없습니다.
글 수와 카테고리 목록 제목도 자동으로 반영됩니다.

소분류 하나는 대분류 하나에 속합니다. 예를 들어 `WEB` 글은 모두 같은
`parentCategory: 보안`을 사용합니다. 서로 다른 대분류에 같은 소분류 이름을
입력하면 어느 분류인지 섞이지 않도록 오류로 알려줍니다.

`pnpm new-post 글이름`으로 만든 새 파일에도 두 항목이 포함됩니다.
기존 글에서 `parentCategory`를 생략하면 `src/config.ts`의 기본 소속을 사용하고,
기본 소속도 없는 소분류는 **기타**에 표시됩니다. 설정 파일은 기존 순서와
글이 없는 카테고리를 유지하는 데에도 사용됩니다.
